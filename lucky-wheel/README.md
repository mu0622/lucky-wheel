# lucky-wheel

一个适配手机和电脑的“刺猬充电大抽奖”网页原型。

## 功能

- 纯静态页面，无需构建工具
- SVG 大转盘与抽奖动画
- 奖品池、活动规则、剩余次数展示
- 中奖结果弹窗
- 进入页面需输入姓名
- 每人每天 1 次抽奖机会，输入“我”或“管理员”不限次数
- 本地获奖名单记录抽奖人和奖品
- 响应式布局，手机和桌面端都可用

## 使用

直接打开 `index.html` 即可预览。

如果使用 GitHub Pages，可以在仓库 Settings -> Pages 中选择从 `main` 分支根目录发布。

## 调整奖品

奖品数据集中在 `app.js` 顶部的 `prizes` 数组中，可以修改：

- `text`：奖品名称
- `detail`：奖品说明
- `chance`：抽奖权重
- `color`：转盘扇区颜色
- `image`：中奖弹窗图片
